# EForge Enterprise

EForge Enterprise is the full-stack enterprise application framework built on:

- **EForge** for the React frontend foundation.
- **RuoYi-Vue backend capabilities** as the server-side baseline.
- **Spring Boot + MyBatis + Redis + MySQL** for enterprise backend infrastructure.
- **OpenAPI** as the front/back contract boundary.

The repository is currently in the architecture-design phase.

See the architecture branch and design documents before implementation begins.

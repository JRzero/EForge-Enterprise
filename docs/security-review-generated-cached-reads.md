## Product integration

relative host boundary used by its existing API/context components. Each list
tracks its generated query, authenticated request options and explicit refresh
version. Success and non-aborted failure complete the ticket; interrupted reads
do not. Activity reactivation preserves a completed list, selection and drafts.
Filter/page/size/refresh changes still reload and clear selection as before.

No DTO duplication, backend database component resolution, cache of credentials,
SQL mutation, permission bypass or scheduler runtime change is introduced.
The host still determines cache eligibility from authorized menu metadata and
evicts pages on identity/permission/navigation transitions. Backend authorization
remains authoritative for every new request.

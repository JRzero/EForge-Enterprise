# Original chart workbench variant

Fixed RuoYi-Vue v3.9.2 index_v1.vue and its PanelGroup/LineChart/RaddarChart/
PieChart/BarChart supply the behavior and attributed MIT sample data. The
existing EForge workbench remains the default. A native view switch opens the
full chart variant, explicitly labelled as demonstration data rather than live
enterprise statistics. No copied Vue application, new endpoint, fake navigation
node or changed dependency/baseline is involved.

Four metric cards retain original totals and count-up durations. Their pointer
and keyboard activation changes the full seven-day expected/actual line data.
Budget radar, article rose and stacked page-visit bar charts retain all original
series/values. SVG charts expose native keyboard legend toggles and complete
accessible data tables; table focus exposes the current chart point. Tooltip
content uses rich text with fixed source data, never arbitrary HTML. Mobile
layout becomes one chart per row and long labels wrap. Reduced-motion users do
not receive count/chart animation.

Each renderer owns its resize observer and disposes both observer and chart on
replacement/unmount. Option updates preserve legend selection without
reinitializing unrelated charts. Initialization/option errors preserve the data
tables and expose per-chart retry. Route authentication/permissions remain the
existing authoritative bootstrap and static dashboard route contract.

Two focused browser fixtures compare independent baseline literals (including
all four first/last-day checkpoints and radar/rose/bar values), actual SVG
renderers, animation totals, keyboard legends and390px bounds. Controlled
persistent observer failure proves all four degraded charts and independent
recovery. Early malformed fixture permission/children values and one-shot
StrictMode fault injection failures are retained and not labelled product
success. Mobile SVG output was visually inspected.

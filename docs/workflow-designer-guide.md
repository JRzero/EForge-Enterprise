# 可视化流程设计器

入口：工作流 → 流程管理 → 新增流程包或编辑 → 可视化设计。需要流程编辑权限，服务端必须启用工作流。

1. 从内置审批流程开始，或在源码模式导入 `.bpmn` / `.xml`。旧文件没有布局时会生成初始布局。
2. 使用顶部按钮添加开始、人工审批、审批分支和结束节点；拖动调整位置。
3. 点击节点或使用“选择节点或连线”，填写名称与稳定标识。人工审批可指定人员、候选人员、候选角色。人员使用账号编号；角色示例为 `role:2`。原有指定人员表达式 `${approver}` 也可保留使用。
4. 点击“应用属性”后再切换节点。选择目标并点击“连接节点”；选择连线可设置批准/拒绝条件。删除节点同时删除关联连线，可撤销。
5. 缩放或“适配画布”查看全图。属性栏提供键盘选择入口，画布获得焦点时支持 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z。
6. 返回源码或导出 BPMN 可得到完整布局和执行定义。调整节点标识后，应同步修改下方审批场景中的任务与结束标识。
7. 保存草稿后执行场景校验。只有当前版本校验通过才能发布；发布后还需单独确认激活。编辑草稿不会修改正在运行的实例。

当前支持既有受限审批节点，不能添加脚本、任意服务调用或复杂会签。无效结构仍由后端拒绝。源码或导入错误时保留原草稿；版本冲突时保留当前编辑，不会自动覆盖其他人的版本。取消未保存修改时会询问是否放弃。

移动端属性栏位于画布下方；流程较宽时可放大并拖动画布。画布右下方 bpmn.io 是依赖许可证要求的署名。

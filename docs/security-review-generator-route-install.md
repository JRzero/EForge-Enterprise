# Generated React route and canonical menu installation

This stage integrates actual generated CRUD/tree/sub pages into the original
Application shell. It does not finish generator management, control variants,
shared shell parity or the active overall goal.

## Code boundary

Velocity emits a JSON-framed SHA-256 identity, ASCII URI path, static React route,
packaged backend declaration and transactional canonical menu SQL. Legal Unicode/
underscore names are retained; list permissions agree across all declarations.
The unchanged Vue/Element Plus/TS SQL template remains a separate compatibility
choice. No backend database string resolves a React component.

MenuRouteCatalog reads only packaged resources plus the built-in contract.
Strict JSON, duplicate ID/path checks, traversal/control/parameter rejection and
immutable options fail closed. Generated names are not silently inserted into the
pinned built-in route contract. MenuService decodes the catalog URI for the legacy
path column. The web registry uses static Vite source imports and rejects duplicate
and noncanonical installed declarations before the Application consumes them.

# 可视化流程设计器

2026-10-10 用户授权继续完成可视化设计器。基于已验收 Flowable 集成，不替换引擎或扩大到表单构建、实例迁移、复杂会签。

## 用户能力

流程包编辑提供可视化画布与 XML 源码切换；创建、拖动、删除开始/人工任务/排他分支/结束节点，连接与删除流转线；编辑标识、名称、审批人/角色、批准或拒绝条件及可选首任务异步属性。支持选择列表的键盘替代、撤销/重做、缩放/适配、XML 导入导出。无布局旧流程自动形成初始布局，已有布局保存重开不丢失。

保留草稿版本与未保存保护；画布保存完整 BPMN XML，后端校验仍权威。源码导入失败保留原内容、不部分替换画布；切换时等待序列化完成，避免保存旧图。只读账号不能进入编辑。

## 实现边界

锁定 bpmn-js 18.31.0；保留官方署名，使用官方 Modeler / moddle 扩展与命令栈。React 复用现有组件实现属性栏，Flowable 类型不进入业务 DTO。后端只新增惰性 BPMN DI 坐标与标准 incoming/outgoing 引用支持，拒绝非有限/超限坐标、未知引用、重复标识、外部内容及可执行扩展。

## 验收

真实画布创建/拖动/连线/属性/撤销与源码往返、旧格式及已存布局、导入错误/失败重试/版本冲突/未保存退出、键盘与四尺寸布局；图形编辑结果由真实 Flowable 校验、发布、激活并执行批准/拒绝。后端安全针对测试、完整回归、客户端复现、前端检查及精确云端验收。不得以渲染一张静态流程图宣称完成。

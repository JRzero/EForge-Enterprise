# 紧凑列表布局

日期：2026-10-12。用户授权评估并优化共享列表布局。

## 设计约定

- 列表以数据浏览为主，沿用浅色/蓝色主题、现有字号与 EForge 控件。
- 参考 Ant Design Pro QueryFilter 的渐进展开和 IBM Carbon 表格工具栏的分层组织，不引入新的组件库。
- 公共 ListFilters 显式指定常用条件数量；简单列表不折叠。用户、角色、字典、参数保留前三项，生成器保留表名/描述，操作日志保留地址/模块/人员，登录日志保留地址/人员/状态，任务保留四个常用条件。
- 其余条件进入“更多筛选”。收起不卸载、不清空、不改变查询条件；显示已填写数量（草稿，非声称已提交）。查询/重置保留原处理函数。
- 搜索区底部间距 12px，内容内边距 16px；标签统一宽度，控件沿用密度设置。分页总数与导航分区。
- 小屏允许换行，操作保持可见可点击，不通过缩小正文字号压缩页面。

## 验收

检查 1440/1024/768/390/320px；桌面日志默认筛选单行；展开/收起、键盘、条件保留、收起后查询、重置和无横向页面溢出。保留权限、错误重试、分页及导出行为。

本轮不改后端查询语义，不将开始/结束日期替换成新日期控件，不改批量操作的权限或展示时机。工作流包页面本身没有搜索表单，只受共享容器和分页间距影响。
